# 🛒 El Papi Store

Proyecto de **Segunda Entrega - JS Flex** (Coderhouse).  
Tienda ficticia con productos de "El Papi" que permite:

- Mostrar un catálogo dinámico generado desde un array de objetos.
- Buscar y filtrar productos por nombre o categoría.
- Agregar productos al carrito con persistencia en `localStorage`.
- Incrementar/disminuir cantidades o eliminar ítems.
- Vaciar el carrito.
- Agregar nuevos productos desde un formulario (se guardan en el navegador).
- Restaurar catálogo (vuelve al array base y borra los agregados).

## 📂 Estructura del proyecto
el-papi-store/
├── index.html
├── styles.css
└── script.js

- **index.html** → maquetado principal, header, buscador, catálogo, carrito, formularios.  
- **styles.css** → estilos con grid/flex, layout responsive.  
- **script.js** → toda la lógica JS (DOM, eventos, storage).  


## ⚙️ Cómo usar
1. Abrir el proyecto en el navegador (`index.html`).  
2. Usar el buscador o el selector de categoría para filtrar.  
3. Agregar productos al carrito → quedan guardados aunque refresques.  
4. Desde el formulario podés crear nuevos productos.  
5. Si querés volver al inicio → **Restaurar catálogo**.
